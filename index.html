Sobre o Café

O Café Aconchego é um café fictício que inventamos para o trabalho da faculdade.

A ideia é um lugar simples e aconchegante, onde as pessoas tomam café e conversam.

Escolhemos esse tema porque é fácil de mostrar com HTML e CSS.

O que você vai encontrar aqui:

  • Cafés quentes
  • Bolos caseiros
  • Pão de queijo
  • Ambiente tranquilo

Passo a passo do nosso aprendizado:

  1. Aprendemos o que é HTML
  2. Aprendemos as tags principais
  3. Aprendemos o que é CSS
  4. Ligamos o CSS no HTML
  5. Publicamos no GitHub

Curiosidade: Esse é nosso primeiro projeto com Git e GitHub!
