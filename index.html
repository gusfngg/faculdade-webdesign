Git e GitHub — Versionamento no VS Code

Usamos o Git dentro do VS Code para versionar o projeto e publicamos o código no GitHub.

  1. Abrimos a pasta no VS Code.
  2. Inicializamos o Git: git init.
  3. Adicionamos os arquivos: git add index.html style.css styles.css.
  4. Fizemos o commit: git commit -m "Atividade box model e flexbox".
  5. Ligamos ao GitHub: git remote add origin https://github.com/gusfngg/faculdade-webdesign.git.
  6. Publicamos: git push -u origin main.
  7. Melhorias novas sempre com add + commit + push.

Repositório do grupo: github.com/gusfngg/faculdade-webdesign
